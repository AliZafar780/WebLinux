🐧 WebLinux — help & shortcuts

What is this?

A complete x86 PC (CPU, BIOS, RAM, disk, VGA) emulated in JavaScript/WebAssembly by the open-source v86 emulator. The Linux distributions below are real, bootable images running entirely inside your browser tab. Nothing is streamed after the initial image download; no server runs your OS.

Things to try

  • uname -a — see the (emulated) kernel
  • cat /etc/issue, busybox --list
  • dmesg | head — real kernel boot messages
  • Networking (select 🌐 Internet above, then in the guest): udhcpc → ping -c 3 1.1.1.1 → wget -O - http://example.com — the virtual NE2000 NIC is bridged to the internet via the public v86 relay
  • DSL: boot the graphical desktop, open Firefox
  • Save state → close the tab → Load state → the machine is exactly where you left it

Privacy

Everything runs in your browser. The distro images are served from this same page (or copied to your disk). No keystrokes or data leave your machine.
